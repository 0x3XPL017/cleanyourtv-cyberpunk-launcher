# Notice & Acknowledgments

## Cyberpunk 2077 SamuraiOS TV Launcher

This project incorporates design concepts, telemetry structures, and automation workflows from:

- **Cyberpunk 2077** (CD PROJEKT RED) — Aesthetics, typography, Samurai Oni emblem, and telemetry UI styling. Used for non-commercial fan customization.
- **cleanyourtv** by Gathin — Automated debloat-and-launcher workflow and ADB tools architecture.
- **Open-Meteo** (open-meteo.com) — Real-time environmental weather telemetry API (free, open data).
- **Google Android Open Source Project (AOSP)** & **Android TV Leanback**.
